# Agent instructions

- Read `docs/Project-Charter.md`, `docs/Game-Design.md`, and `docs/Technical-Production-Plan.md` before making project changes.
- Treat each document as authoritative only for its stated responsibility; cross-reference instead of duplicating decisions.
- Keep work bounded to the current milestone and preserve unrelated changes.
- Distinguish proposed, open, deferred, and confirmed direction from validated results.
- Do not create the Godot project or game code until the foundation documents and tooling are reviewed and the task explicitly authorizes it.
- Verify changes and inspect staged files before committing; never commit credentials or unreviewed third-party assets.
